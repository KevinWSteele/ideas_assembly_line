# Stage 1: Ideas

This is the entry point of the pipeline — pure proposals, no code required.

**What goes here:** a short write-up proposing a tool or system you think would be genuinely useful, for a **specific, named target user**. "Useful for everyone" isn't specific enough — say exactly who this is for and what problem it solves for them.

**Who can contribute:** anyone. This is the lowest-barrier stage in the pipeline on purpose — if you can describe a problem and a plausible solution, you can submit here, regardless of technical background.

**How to contribute:**
1. Copy [`TEMPLATE.md`](TEMPLATE.md) into a new file in this folder.
2. Name it `idea-<your-slug>.md` (e.g. `idea-meeting-digest.md`).
3. Fill it in. Keep it short — a clear paragraph or two per section is plenty.
4. Open a Pull Request (see the [root README](../README.md) for how).

**Worked example:** [`example_idea.md`](example_idea.md) — read this first to see the level of detail expected.

Once your idea is here, anyone can pick it up and build a prototype from it in [`2-prototypes/`](../2-prototypes/) — you don't have to build it yourself, and you're welcome to build someone else's.
